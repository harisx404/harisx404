## Featured projects

### [TourMate Malakand](https://tourmate-malakand.vercel.app)
**Full-stack tourism and geospatial platform** · [Frontend](https://github.com/harisx404/tourmate_malakand_frontend) · [Backend](https://github.com/harisx404/tourmate_malakand_backend)

A regional tourism platform combining destination discovery, interactive maps, route planning, weather information, emergency contacts, and protected administration.

`React` `Vite` `Node.js` `Express` `MongoDB` `Mapbox GL JS` `Cloudinary`

### [IntruShield NIDS](https://github.com/harisx404/intrushield-nids)
**Network intrusion detection and SOC telemetry**

A defensive security platform that streams Suricata alerts to a real-time dashboard, enriches events with GeoIP data, and helps analysts inspect and manage network threat telemetry.

`Python` `FastAPI` `Suricata` `Next.js` `WebSockets` `PostgreSQL` `Docker`

### [PacketVision](https://github.com/harisx404/packet-vision-network-sniffer)
**Multithreaded network packet analyzer**

A CLI network inspection tool with protocol dissection, packet filtering, bounded-queue processing, terminal-output sanitization, and PCAP/JSON/CSV export.

`Python` `Scapy` `Raw Sockets` `Multithreading` `BPF` `PCAP`

### [Mail-Lens AI / PhishGuard AI](https://github.com/harisx404/phishguard-ai)
**Explainable NLP email threat detection**

Classifies email as legitimate, phishing, or malicious and provides interpretable signals behind its predictions. Project documentation reports 98.64% accuracy on a holdout set and CPU inference under 15 ms per email.

`Python` `scikit-learn` `NLP` `TF-IDF` `LinearSVC` `Explainable AI` `Streamlit`

### [MedicaLink HMS](https://github.com/harisx404/MedicaLink-HMS)
**Multi-tenant hospital management platform**

A healthcare workflow application designed around tenant isolation, role-based access, real-time clinical queues, and AI-assisted documentation. It is a software project, not a claim of third-party healthcare compliance certification.

`TypeScript` `React` `Node.js` `Express` `MongoDB` `Redis` `Socket.IO` `Gemini`

### [Harisx404 Portfolio](https://harisx404.vercel.app)
